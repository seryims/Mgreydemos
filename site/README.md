# Видео в первом экране maximgrey.ru

`index.html` — изменённая версия сайта. В первом экране вместо нарисованного
чата теперь demo-видео: вкладки остались, меняется содержимое.

## Что загрузить на хостинг

Рядом с `index.html` положить папку `media/` со всеми файлами ниже.

Из этой папки (уже готовы):

    media/booking_loop.mp4        media/booking_poster.jpg
    media/subscription_loop.mp4   media/subscription_poster.jpg
    media/shop_loop.mp4           media/shop_poster.jpg
    media/digital_loop.mp4        media/digital_poster.jpg
    media/content_loop.mp4        media/content_poster.jpg

Из папки `output/` этого репозитория скопировать в `media/` без переименования:

    BodyHarmony_booking_showcase_9x16_web.mp4
    VasKristi_bot_showcase_9x16_web.mp4
    Fitoteka_miniapp_showcase_9x16_web.mp4
    VasKristiShop_bot_showcase_9x16_web.mp4
    VKBridge_sync_showcase_9x16_web.mp4

Итого: `index.html` + 15 файлов в `media/` (~53 МБ).

## Как это работает

- В шапке крутится короткая петля 12 с, 540×960, без звука, ~0,5 МБ.
  Полный ролик (9–12 МБ) грузится только по кнопке «Полный ролик».
- Пока петля не загрузилась, показывается постер-кадр (~45 КБ), пустоты нет.
- Петля активной вкладки начинает грузиться, только когда первый экран
  появился в зоне видимости.
- Кнопка «Полный ролик» открывает видео со звуком поверх страницы.
  Закрытие: крестик, клик мимо, Esc.
- Кнопка 🔇 включает звук прямо в шапке.
- При «Экономии трафика» и в режиме «Уменьшить движение» видео не грузится —
  остаётся постер.
