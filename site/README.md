# Видео на maximgrey.ru

`index.html` — изменённая версия сайта. Рядом с ним нужна папка `media/`.

## Что изменилось

1. **Первый экран.** Вместо нарисованного чата — демо-видео. Вкладки остались,
   меняется содержимое. Ролик стартует сам, без звука, и когда заканчивается —
   автоматически переключается на следующий проект. Пять роликов идут по кругу.
2. **Лайтбокс проектов.** Раньше одна запись экрана была вшита в HTML кодом
   base64 — из-за неё файл весил 5,7 МБ. Теперь ролики подключены файлами,
   страница весит 218 КБ. Видео в лайтбоксе тоже запускается само и без звука,
   снизу кнопка «🔊 Включить звук».
3. **Кнопки «Смотреть видео»** добавлены в карточки «Цифровые товары»,
   «Eco NeuroNova» и «Бот записи». В карточке «Рационы питания» вторая кнопка —
   «Синхронизация с ВК».
4. Пятая вкладка в шапке: «Заготовки» → «ВКонтакте».

## Что загрузить на хостинг

## Как это работает

- В шапке идёт нарезка 12 с, 540×960, без звука, 0,4–1,1 МБ. По окончании
  автоматически включается следующий проект, вкладка и точки-пагинация
  переключаются сами.
- Когда первый экран уходит за пределы видимости, видео ставится на паузу
  и возобновляется при возврате.
- Полный ролик (5–11 МБ) грузится только при открытии лайтбокса.
- До загрузки виден постер-кадр (~45 КБ), пустого места нет.
- Кнопка 🔇 в шапке включает звук петли.
- Лайтбокс закрывается крестиком, кликом мимо и по Esc.
- При «Экономии трафика» и в режиме «Уменьшить движение» видео не грузится —
  остаётся постер.
- При уходе на другую вкладку браузера видео ставится на паузу.

## Что поправлено в вёрстке

- На экранах уже 420 px страница разъезжалась вправо: полоса вкладок распирала
  сетку первого экрана. Добавлен `min-width:0` — горизонтальной прокрутки
  больше нет.
- На телефоне видео занимало 270 px при ширине экрана 360. Теперь оно во всю
  ширину колонки.
- Кнопка звука перенесена в правый верхний угол видео, чтобы не перекрываться
  плавающей кнопкой «наверх».

## Про анонимные демо

В роликах «Магазин» и «Запись» названия и оформление вымышленные — это
демо-сборки на базе рабочих проектов. В подписи к видео это указано.
