обо мне

Максим

Пишу продовых ботов на Python для Telegram, WhatsApp, Instagram и MAX — не прототипы «на посмотреть», а сервисы, которые обрабатывают оплаты, ведут расписание и выдерживают наплыв заявок.

Отдельно слежу за тем, что обычно ломается в чужих ботах: гонки при одновременной записи, потеря сообщений при перезапуске, забытые напоминания. Использую транзакции с блокировкой, очереди задач и авто-восстановление после падений.

Платформы
Telegram, WhatsApp, Instagram, MAX — под каждую платформу свой API и особенности, сценарий проектирую с учётом её ограничений.
Что делаю
Боты-подписки с приёмом оплаты, магазины с Mini App/каталогом, запись и CRM-уведомления, интеграции с ChatGPT, СДЭК и платёжными системами (ЮKassa, CloudPayments, Т-Банк, Робокасса, Prodamus).
На чём
Python 3, aiogram 3, SQLAlchemy + Alembic, SQLite/Postgres, Redis (FSM-хранилище), APScheduler.
Как сдаю
С логами, ротацией, резервными копиями БД и базовыми автотестами — чтобы после сдачи проект не остался «чёрным ящиком».
